# Lesson 9

## Conjugating 이다

### Present Tense

| **Respect Level**     | **Attachment**  | **Example**                              |
| --------------------- | --------------- | ---------------------------------------- |
| Informal Low Respect  | ~(이)야         | 나는 좋은 학생이야 = I am a good student |
| Informal High Respect | ~이에요 / ~예요 | 그것은 사진이에요 = That is a picture    |
| Formal High Respect   | ~입니다         | 저는 의사입니다 = I am a doctor          |

---

### Past Tense

| **Respect Level**     | **Attachment**          | **Example**                                    |
| --------------------- | ----------------------- | ---------------------------------------------- |
| Informal Low Respect  | ~이었어 / ~였어         | 나는 학생이었어 = I was a student              |
| Informal High Respect | ~이었어요 / ~였어요     | 그것은 큰 비밀이었어요 = That was a big secret |
| Plain Form            | ~이었다 / ~였다         | 나는 선생님이었다 = I was a teacher            |
| Formal High Respect   | ~이었습니다 / ~였습니다 | 저는 선생님이었습니다 = I was a teacher        |

---

### Future Tense

| **Rule**                  | **Attachment**     | **Example**                                       |
| ------------------------- | ------------------ | ------------------------------------------------- |
| Conjugation with **이다** | ~ㄹ/을 것이다      | 나는 행복할 것이다 = I will be happy              |
| Shortened Form            | ~ㄹ/을 거예요      | 저는 밥을 먹을 거예요 = I will eat rice           |
| Using 되다 (to become)    | ~이/가 + 될 것이다 | 나는 선생님이 될 것이다 = I will become a teacher |

---

### Irregular Forms for ~ㄹ/을

| **Irregular Type** | **Attachment** | **Example**        |
| ------------------ | -------------- | ------------------ |
| ㅅ Irregular       | ~ㄹ            | 짓다 → 지을 것이다 |
| ㄷ Irregular       | ~을            | 걷다 → 걸을 것이다 |
| ㅂ Irregular       | ~울            | 돕다 → 도울 것이다 |
| ㄹ Irregular       | ~ㄹ            | 열다 → 열 것이다   |

## Conjugating 아니다

| **Attachment** | **Example**               |
| -------------- | ------------------------- |
| With 아니다    | ~이/가 + 아니다           |
| With 되다      | ~이/가 + 되지 않을 것이다 |

---

## Guessing (Using Future Form for Present Tense)

| **Attachment** | **Example**          |
| -------------- | -------------------- |
| With 이다      | ~일 것이다           |
| With 아니다    | ~이/가 + 아닐 것이다 |

## Additional Notes

1. **Contractions**: When conjugating 이다, contractions such as ~였어 (past tense) and ~거예요 (future tense) are common in spoken Korean.
2. **되다 Usage**: Often used interchangeably with 이다 in the future tense for "to become."
3. **Speaker Guessing**: Future tense conjugation of 이다 can also imply present-tense guessing based on context.
