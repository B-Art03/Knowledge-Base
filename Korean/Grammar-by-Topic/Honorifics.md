# Honorifics

| | Past              | Present | Future |
| - | :----------------: | :------: | :----: |
| Informal Low Respect | ~었어/았어/였어 | ~어/아/여 | ~겠어 |
| Informal High Respect | ~었어요/았어요/였어요 | ~어요/아요/여요 | ~겠어요 |
| Formal High Respect | ~었습니다/았습니다/였습니다 | ~ㅂ니다 (no 받침), 습니다 (with 받침) | ~겠습니다 |
